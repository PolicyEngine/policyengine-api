Catalog publication now prunes older v2 catalog versions after it commits: for each country it keeps the installed PolicyEngine.py version and the most recently created other one, and deletes every other stored version's current-law parameter values, parameter tree rows and parameter search file, recording when in `tax_benefit_model_versions.catalog_values_pruned_at` and reporting what it deleted, and any failure, in its evidence. Publishing a pruned version again restores those rows identically from the installed packages. For a pruned version, `/v2/parameter-values`, `/v2/parameter-values/{value_id}`, `/v2/parameters/children`, `/v2/parameters/search-file`, `/v2/model-catalog/variables` and `/v2/model-catalog/parameters` return 503 with `Cache-Control: no-store`; the other metadata routes answer as before.
