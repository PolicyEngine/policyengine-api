`PATCH /{country_id}/simulation` and `PATCH /{country_id}/report` no longer change a complete result: an update that repeats it returns the record unchanged, and one that would change it answers 409. A simulation result from an older country model can still be replaced by the installed model's, and an update to an outdated report ID now completes its current equivalent, the record reads serve for that ID, instead of the outdated row. Both routes reject a non-integer `id` and a completion whose output is null.
