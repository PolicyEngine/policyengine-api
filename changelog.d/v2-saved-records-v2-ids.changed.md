`/v2/user-reports` accepts a v2 `report_id` and `/v2/user-simulations` a v2 `simulation_id`, alone or with the v1 ID, when a record is saved or repointed; the simulation service is asked first whether the report or simulation exists in the country, and an unknown one is a 422. A saved report or simulation holding both IDs must name the v2 record migrated from that v1 record, or the request is a 400. A shared report (`/v2/shared-reports/{id}`) now shows its `report_id`.
