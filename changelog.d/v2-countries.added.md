Added a v2 `countries` table that lists each country with a display name and whether it supports household and society-wide calculations, and `GET /v2/countries`, which returns every listed country. The US and the UK are listed with both. Users' primary country and the country of every v2 household, policy and user association now reference this table instead of a fixed US-and-UK check, so listing another country needs a row rather than a schema change.
