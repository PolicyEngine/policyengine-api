Added `/v2/reports` for economy reports, which the simulation service calculates and stores. `POST /v2/reports` creates a report and its first run on the country's current catalog version. `GET /v2/reports/{report_id}` and `GET /v2/reports/by-legacy-number/{number}` read one, and reading a report that has never run, such as one migrated from v1, starts its first run. `POST /v2/reports/{report_id}/runs` runs a report again on the current catalog version, reusing existing simulation runs unless `force` is set, and `GET /v2/reports/{report_id}/runs` lists its runs with their versions. A country whose `countries` row does not allow society-wide calculations gets a 422 naming it when it submits or re-runs a report, before anything is sent to the simulation service.
